# Fonts

Self-hosted variable fonts, Latin subset, taken from the Fontsource packages
(`@fontsource-variable/*`). All three are licensed under the SIL Open Font License 1.1,
which permits bundling and web use.

| File | Family | Used for |
| --- | --- | --- |
| `inter-latin-wght-normal.woff2` | Inter | Body text and interface, both palettes |
| `cormorant-garamond-latin-wght-normal.woff2` | Cormorant Garamond | Headings, light-grey palette |
| `newsreader-latin-wght-normal.woff2` | Newsreader | Headings, light-blue palette |
